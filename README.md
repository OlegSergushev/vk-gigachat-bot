# 🤖 Марвин — VK-бот с GigaChat

Пессимистичный робот-параноик с планеты Марс, который отвечает на вопросы, рассказывает анекдоты и постоянно жалуется на жизнь. Построен на VK LongPoll API и GigaChat.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![VK API](https://img.shields.io/badge/VK%20API-LongPoll-0077FF)
![GigaChat](https://img.shields.io/badge/GigaChat-Sber-21A038)

---

## ✨ Что умеет

- 💬 **Ведёт диалог** с историей контекста (последние 10 сообщений)
- 🎭 **Играет роль Марвина** — саркастичного робота из «Автостопом по Галактике»
- 📚 **Рассказывает анекдоты** из локальной JSON-базы с поиском по ключевым словам
- 🎹 **Inline-клавиатура** с кнопками «Помощь» и «Очистить диалог»
- 🛡️ **Анти-спам** — игнорирует сообщения чаще, чем раз в 0.5 секунды
- 🎯 **Реагирует только на обращения** — по имени «Марвин», через `@username` или в личных сообщениях

---

## 🧠 Как работает

1. Бот слушает события через **VK LongPoll**
2. Если сообщение адресовано боту (личка, `@username` или слово «Марвин») — обрабатывает
3. Если просят анекдот — ищет в локальной базе по ключевым словам
4. Отправляет запрос в **GigaChat** с системным промптом Марвина
5. Возвращает ответ (с историей диалога)
